{# Chant styles shared by the index (chanting.html) and the page-by-page reading view (chanting_page.html). Both surfaces show the same verses with the same five layers, and the layer toggles write one setting that has to mean the same thing on both. Keeping the styles in one file is what stops the two drifting apart — a page that styles a verse differently from the index is a page that reads as a different book. This is a template rather than a static .css file because the layer COLOURS are generated from CHANT_LAYERS in chanting.py, so there is one source of truth for each layer's colour: the text, its left rule and the swatch on its toggle all come from the same value. Any template including this must be rendered with `layers`. Styles for the index grid itself (.chant-grid, .chant-card) stay in chanting.html — the page view has no cards. #}
