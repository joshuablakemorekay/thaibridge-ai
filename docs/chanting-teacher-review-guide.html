Teacher Review Guide: Chanting Book Proof Copy

Chanting Book: Morning and Evening Service, Wat Mahathat United Kingdom edition. Prepared by Pra Joshua Vajira Panyo with ThaiBridge AI.

What you are checking

The proof is 572 pages and 305 chants. Every chant has five layers and a short note:

  • The Pali in Thai script
  • The same Pali in the Latin alphabet
  • The Thai translation
  • The Thai in ThaiBridge Spelling (to read aloud)
  • The English translation
  • A note: When it is chanted, Historical background, Meaning and purpose

Your main job is accuracy. The English is a working translation that has not yet been checked by a teacher, so it matters most. Please do not worry about layout. A few small formatting glitches, such as stray tags and some Contents titles, are known.

What is new since the last version

  • A publishing page (p. 2), a With thanks section (p. 4) and A guide to pronunciation (pp. 5–6), covering Pali and ThaiBridge Spelling. Please check the guide too.
  • 168 new ThaiBridge Spelling lines under Thai translations in 13 chants. They are drafts and have not yet been checked. The separate PDF “3 - Review - new ThaiBridge Spelling lines (23 pages)” shows only those pages, with each new line highlighted in yellow. Please give these lines a careful listen, especially the tones.
  • In this book a final ย is written i (dûai, nɔ́ɔi) and a final ว o (lɛ́ɛo). This is deliberate, so please do not mark it as a mistake.

Steps, in this order

Each step builds on the one before. The Pali comes first because every other layer is made from it.

  1. Orient (15 minutes). Read the Preface, “About this edition”, “How each verse is set” and the pronunciation guide (pp. 3–6).
  2. Pali in Thai script. Compare it with the printed temple book. Each chant shows “Book page ##” to help.
  3. Romanised Pali. Does it match the Thai-script Pali? Look for wrong letters, missing marks and wrong word breaks.
  4. Thai translation. Does it give the real meaning? Is anything missing?
  5. English. Compare it with the Pali and the Thai meaning.
  6. Notes. Mark any claim about origin, use or meaning that you cannot confirm.
  7. ThaiBridge Spelling. Read it aloud. Does it sound like the Thai? Start with the 23 highlighted pages.
  8. Send back one list (format below).

Where to start

  • Sample first (about 10 chants): Morning opening (pp. 14–25), the Maṅgala Sutta (p. 164) and the Ratana Sutta (p. 168).
  • Then the most-chanted parts: the Evening Service (pp. 108–117).
  • Then the new spelling lines: pp. 416–432, 438–440, 532–533 and 541 (the 23 highlighted pages).
  • Then the rest, as time allows.

If the sample looks clean, you can move faster through the remaining chants.
