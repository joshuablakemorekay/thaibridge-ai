# Asking Google to update a page

Visitors see changes to the web app straight away. Google only revisits pages
every so often, so search results can take days or weeks to catch up. For most
changes that's fine and you don't need to do anything.

For an **important** change (new prices, a new page, a big fix), you can ask
Google to come sooner:

1. Open https://search.google.com/search-console and make sure you're signed
   in as **joshua@smoald.com**. Chrome tends to open the watmahathat account
   first, so switch with the account picker at the top right.
2. In the property box at the top left, pick **jaiway.smoald.com**.
3. Click the search bar at the very top ("Inspect any URL").
4. Paste the full page address, e.g. `https://jaiway.smoald.com/premium`,
   and press Enter.
5. Wait a few seconds for the result.
6. Click **Request indexing**.
7. Wait about a minute while Google runs a quick check. When it says
   **"Indexing requested"**, you're done.

## Tips

- Only do this for important changes.
- One page at a time. Google allows roughly 10 or so a day.
- "URL is not on Google" is normal for new pages. Still click
  **Request indexing**.
- Google's results usually catch up within a day or two of a request.
- New public pages are added to the sitemap automatically
  (`https://jaiway.smoald.com/sitemap.xml`), so you never need to edit it.
