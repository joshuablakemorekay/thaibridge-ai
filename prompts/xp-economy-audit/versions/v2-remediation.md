# v2 — the remediation

Asked once the audit came back, naming which finding mattered most.

```
How can we fix this? Especially so that a free user watches a progress bar fill
up toward a reward that doesn't exist issue can be fixed.
```

## What changed from v1

v1 asked for a diagnosis. v2 asked for options **and set the priority** — the
second sentence rules out an answer that fixes the security holes and leaves the
free tier as it was.

## What it produced

Three options for the free-user problem:

1. Re-level the free sections so they ladder — rejected, it would gate Dhamma
   content that is deliberately free.
2. Badges and streaks instead of access — rejected as treating the symptom.
3. Let XP buy one real paid section — shipped.

Plus an ordered fix plan across all four findings, security first.
