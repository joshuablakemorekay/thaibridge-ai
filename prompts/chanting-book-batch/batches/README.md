# Batch files

One JSON file per batch of photographed pages, written by **Stage 1** and read
by **Stage 2**. Named by the pages they cover — `batch-041-049.json` — because
pages are the unit this book is built on, not filenames.

These are kept rather than deleted after a batch lands. They are the only record
of what each photograph actually said: `chanting.py` holds what went into the
app, and the physical book is on a shelf, but a disagreement between the two is
only diagnosable if the reading in between survived.

They also hold what did not make it into the app — the page map, the working
notes, and every check with the filename of the photograph it came from.
