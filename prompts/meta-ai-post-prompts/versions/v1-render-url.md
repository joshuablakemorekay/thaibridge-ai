# v1 — As drafted and run (2026-09-17)

**Status:** superseded by v2; kept because the flaw is the point

This is the version that was actually pasted into Meta AI. Section 5 of the
text prompt read:

> 5. Call to Action (CTA): "Try the free lessons at thaibridge-ai.onrender.com, then unlock Sentences to learn all three politeness levels."

## What was wrong with it

`thaibridge-ai.onrender.com` is the Render hosting URL. The live site, the
README and all four coursework documents use the custom domain
`thaibridge-ai.smoald.com`. A post carrying the hosting URL advertises the
scaffolding instead of the address, and the two would disagree the moment the
host changed.

Nothing caught it at drafting time. It was found while writing this folder's
rubric, by asking what a *wrong* output would look like — which is the
argument for writing the rubric at all.
