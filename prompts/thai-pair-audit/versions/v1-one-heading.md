# v1 — one heading

The question asked about a single line on the home page.

```
Also there are corrections that need to be made, some of the Thai script doesn't
match, eg, 🪷 ThaiBridge AI
Learn the Dhamma. Learn Thai. Find Your Own Path.
พระธรรมและภาษาไทย - On Homepage here does the Thai script match the English?
```

## What worked about it

It is answerable. "Check my Thai" is not — it invites an essay. "Does this line
match that line" has a yes or a no, and the answer can be checked by anyone.

Attaching the actual text rather than the file path also mattered: the mismatch
is visible in the quoted lines themselves, so the question carries its own
evidence.

## What it produced

No. `พระธรรมและภาษาไทย` is *"the Dhamma and the Thai language"* — a noun phrase
where the English is three instructions. Grammatical Thai, wrong Thai for that
line, and invisible to any spellchecker.

That last part is what justified generalising it.
